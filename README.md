# Aster – Fashion & Clothing Website

Aster is a modern clothing brand website designed to showcase timeless fashion essentials through a clean, elegant, and user-friendly interface.

The project focuses on creating a refined online shopping experience with a natural colour palette, minimalist design, and responsive layouts.

## Features

- Modern and minimalist user interface.
- Responsive design for desktop, tablet, and mobile devices.
- Clothing product showcases.
- Clean navigation and structured page layouts.
- Elegant typography and natural colour palette.
- Interactive elements using JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript
